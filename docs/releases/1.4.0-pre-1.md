## 中文

相比 1.3.1 的更新。本版本为非正式版本。正式版前如在使用中遇到问题请向我们反馈，后续将与发现的新问题一并修复。  
当前版本在Windows设备上进行测试，安卓手机上测试明确存在UI安全区问题导致交互不便，1.4.0版本暂不更新

### 重要更新

- 音乐墙与音乐库整合，统一提供「创建的歌单」「收藏的歌单」「收藏的专辑」三个分类，支持多层文件夹管理。
- 播放器整合到音乐库内，可从底部展开全屏播放器，收起后继续浏览。
- 音乐墙改为统一数据文件保存，旧 `.mw` 文件不再作为独立音乐墙打开。升级前请备份原有数据。

### 新增

- 支持收藏网易云歌单，以及创建独立于网易云账号的本地歌单。
- 本地歌单支持修改名称、简介和曲目；支持将现有歌单克隆为同名、同曲目顺序的本地歌单。
- 支持 Ctrl／Command 点击多选、Shift 连续选择，以及正文和侧边栏拖拽排序。
- 支持将歌曲拖入本地歌单进行复制，将专辑、歌单拖入文件夹进行移动。
- 支持将搜索结果中的专辑、歌单拖入侧边栏收藏，并阻止同一位置重复添加。
- 新增音乐墙彩胶样式，根据专辑封面取色。
- 支持恢复上次播放的歌曲、队列和来源；恢复后保持暂停，不恢复播放进度。
- 新增艺术家专辑筛选，可按单曲、混音、曲目数量和关键词筛选。
- 专辑列表增加发行年月展示，音乐库专辑详情中的艺术家名称支持跳转至艺术家详情。
- 新增歌词浏览时间提示，可跳转到预览歌词对应的播放位置。

### 调整

- 收藏的专辑和歌单在打开详情时联网加载最新内容。
- 账号歌单入口调整为「账号创建歌单」「账号收藏歌单」，与音乐墙中的本地收藏区分。
- 音乐墙展示样式改为全局统一。专辑网格样式依次为封面、黑胶、彩胶、CD、磁带；歌单网格和列表模式使用封面。
- 保留排序、添加、墙内搜索及布局切换，直接拖拽即可调整顺序。
- 返回按钮和鼠标侧键按浏览历史返回上一页。
- 优化长歌曲列表的分页、滚动及窗口缩放性能。
- 优化横屏、竖屏、窄屏及低高度窗口布局；音乐墙首页变窄时优先收紧入口间距，竖屏采用纵向排列。
- 统一主题色为 `#1D4E89`，彩色播放器继续跟随封面取色；优化深浅主题、控件尺寸和侧边栏动画。
- 歌曲名与艺术家名称保持单行，超长内容滚动显示。
- 墙导入导出入口暂时隐藏。
- Git 功能暂时禁用，下一个版本或后续版本会对功能进行重做。

### 修复

- 修复部分歌曲的封面背景加载失败、背景取色未完成时显示异常的问题。
- 修复插入单曲后，播放队列名称被歌曲名称替换、歌曲来源显示错误的问题。
- 修复移除当前歌曲之前的曲目后，当前歌曲索引与实际播放内容不一致的问题。
- 修复播放专辑期间追加歌单时，专辑曲目混入歌曲队列的问题。

### 移除

- 移除创建独立音乐墙及旧 `.mw` 文件的编辑入口。
- 移除旧音乐墙分组、布局预览和展示架，改用文件夹层级与统一展示样式。
- 移除独立播放器标签页及对应侧边入口。
- 移除多选模式、拖拽排序模式按钮及墙内筛选入口。
- 移除插件控件的原生鼠标悬停气泡提示。

## English

Changes since 1.3.1. This is a prerelease. Please report any problems you encounter before the stable release; they will be addressed together with newly discovered issues.  
This version has been tested on Windows. Testing on Android phones has confirmed UI safe-area issues that make interaction difficult, so Android will not receive the 1.4.0 update for now.

### Highlights

- Integrated Music Wall with the music library, with three categories: Created playlists, Saved playlists and Saved albums. All three support nested folders.
- Integrated the full player into the music library. Expand it from the bottom and collapse it to continue browsing.
- Music Wall now uses one data file. Old `.mw` files no longer open as independent music walls. Back up your existing data before upgrading.

### Added

- Added saved NetEase playlists and local playlists that are independent of your NetEase account.
- Local playlists support editing names, descriptions and songs. Existing playlists can be cloned into local playlists with the same name and song order.
- Added Ctrl/Command-click selection, Shift-click range selection, and drag sorting in both the main area and sidebar.
- Drag songs into local playlists to copy them; drag albums and playlists into folders to move them.
- Drag albums and playlists from search results into the sidebar to save them. Duplicate items cannot be added to the same location.
- Added a colored vinyl style for album walls, using colors sampled from album artwork.
- Added restoration of the last song, queue and sources. Playback stays paused after restoration, and playback progress is not restored.
- Added artist album filters for singles, remixes, track count and keywords.
- Album lists now show release year and month. Artist names in library album details link to artist details.
- Added time previews while browsing lyrics, with an action to seek to the previewed line.

### Changed

- Saved albums and playlists fetch their latest contents when you open their details.
- Renamed the account playlist entries to Account created playlists and Account saved playlists, distinguishing them from local Music Wall collections.
- Music Wall display settings are now shared globally. Album grid styles are ordered Cover, Vinyl, Colored vinyl, CD and Cassette. Playlist grids and all list layouts use covers.
- Retained sorting, adding, in-wall search and layout switching. Drag directly to arrange items.
- Back buttons and mouse side buttons now return to the previous page in browsing history.
- Improved pagination, scrolling and window resizing performance for long song lists.
- Improved landscape, portrait, narrow and short-window layouts. The Music Wall home page reduces spacing as the main area narrows and stacks its entries vertically in portrait panes.
- Unified the theme accent as `#1D4E89`, while colored player styles continue to use artwork-derived colors. Improved light and dark themes, control sizes and sidebar animations.
- Song and artist names stay on one line, with scrolling for overflowing text.
- Temporarily hid wall import and export entries.
- Git features are temporarily disabled and will be redesigned in the next or a later version.

### Fixed

- Fixed artwork backgrounds failing to load for some songs and incorrect display before background color sampling completed.
- Fixed inserting a song replacing the queue name with the song name and displaying incorrect song sources.
- Fixed removing songs before the current song causing its index to disagree with the song actually playing.
- Fixed album tracks being mixed into the song queue when appending a playlist during album playback.

### Removed

- Removed the entries for creating independent music walls and editing old `.mw` files.
- Removed old wall groups, layout previews and shelf layouts, replaced by nested folders and shared display settings.
- Removed the standalone player tab and its sidebar entry.
- Removed selection-mode and drag-sorting-mode buttons, along with the in-wall filter entry.
- Removed native hover tooltips from plugin controls.
