# Music Wall（音乐墙）

把你的网易云音乐专辑，像真正的唱片一样摆上 Obsidian 里的一面墙。

每张专辑可以长成黑胶、CD、磁带或纯封面四种样子，整整齐齐码在墙上；
点一下唱片，就能直接在 Music Wall 内播放它。你收藏过什么、想听什么，
一眼就能看到。

所有收藏都存在你自己库里的一个 `.mw` 文件里——它就是一个普通文本文件，
可以发给朋友、可以备份，一切都在你自己手上。

## 三分钟上手

### 第一步：把插件装进 Obsidian

1. 找到你的 Obsidian 库所在的文件夹；
2. 在里面找到 `.obsidian` 文件夹 → `plugins` 文件夹（找不到 `.obsidian`？
   它是隐藏文件夹，Windows 在文件管理器「查看」里勾选「隐藏的项目」就能看到）；
3. 在 `plugins` 里新建一个叫 `music-wall` 的文件夹，把 **main.js、styles.css、
   manifest.json** 三个文件放进去；
4. 回到 Obsidian：设置 → 第三方插件，刷新后打开 **Music Wall** 的开关。

> 提示：本插件的发布页会提供这三个文件的打包下载，解压照做即可。

### 第二步：建一面墙

三选一，看哪个顺手：

- 在左边文件列表里**右键任意文件夹** → 选「新建音乐墙」；
- 点 Obsidian 最左侧边栏的**唱片图标**；
- 按 `Ctrl+P` 打开命令面板，输入「音乐墙」选对应命令。

墙上立刻出现一个新标签页——这就是你的第一面（暂时还空着的）音乐墙。

### 第三步：摆上第一张专辑

1. 点墙右上角的 **＋** 按钮，右上角会弹出一个小面板；
2. 输入专辑名（比如「范特西」）回车，从结果里挑出你要的那张；
   - 小技巧：直接把网易云 App 里「分享 → 复制链接」得到的链接贴进来也行；
   - 想一次加很多张：点面板里的「**批量**」按钮，把每张专辑的编号用分号隔开贴进去
     （编号就是网易云网页版专辑地址里 `id=` 后面的那串数字）；
3. 弹出的确认窗口里核对封面和曲目，点确认——唱片上墙了。

### 第四步：听

点一下墙上的唱片 → 在弹出的详情窗口里点播放。
默认在插件内按专辑曲目顺序播放，不需要安装网易云客户端，也不创建或替换账号歌单。
播放器页支持暂停、上一首/下一首、点击曲目、进度跳转和音量控制。
在命令面板中也可暂停/继续或停止插件内播放。

**首次试听或播放会弹出登录二维码**，用网易云手机 App 扫描并确认即可，
也可以到插件设置中扫码登录或登出。浏览、搜索和整理收藏无需登录。
播放队列只保留在内存中；关闭播放器标签页仍可继续听，停止播放、登出或关闭插件会清空队列。
设置中可以切回原来的「网易云客户端播放」；该模式整专连播仍使用专用歌单。

到这里你已经会用了。下面这些是锦上添花。

## 玩出花样

### 🎨 唱片的样子和墙的摆法

- **四种样子**：黑胶、CD、磁带、纯封面，随时换，整面墙一起变；
- **三种摆法**：网格（大海报式）、列表（紧凑一行行）、**展示架**
  （一面深色木架，唱片斜倚着，鼠标放上去会抽出来，黑胶还会滑出半张慢慢转）。

都在墙顶栏第一个图标「样式与布局」里，每个样式都有真实缩略图预览，
看哪个顺眼点哪个。你的选择会被记住，下次打开还是老样子。

### 🗂 分组：把墙分成几个区

在墙的空白处**点右键** →「新建分组」，就能把唱片分门别类
（比如「华语」「跑步听的」）。分组可以折叠、改名、排序；
想删掉一个分组时，如果里面还有唱片，需要你亲手输入分组名确认，
防止手滑。

### 🔃 找唱片：排序、筛选、搜索

- **排序**：手动排（长按进入布局编辑后直接拖）、添加时间、专辑名、
  艺术家、发行时间、**评分**——想怎么排就怎么排，正排倒排随意组合；
- **筛选**：按艺术家、年代、评分挑，可以多选（比如只看「周杰伦」
  或只看评了 5 星的）；
- **搜索**：右上角放大镜，直接按关键词翻你的收藏。

### ⭐ 给专辑打分

右键任意唱片 →「**评分…**」，给 1 到 5 颗星。打完分的唱片
右上角会多一颗小星星，写着分数；详情里也会亮出对应星数。
之后可以按评分排序（把最爱的放最前）、按评分筛选（只看高分）。

评分存在墙文件里——把墙分享给朋友时，你的评分也会一起过去。

### ☑ 多选和批量搬家

顶栏「**多选**」进入挑选模式：点一张选中一张，然后可以一次性
把它们**批量迁移到另一面墙**。直接把选中的一叠拖到另一面
已打开的墙上也成。

### 🧱 很多面墙与搬家

墙不止一面：想建几面建几面（「华语精选」「2026 听后感」……）。
右键唱片 →「迁移到其他墙…」就能把唱片搬过去，按专辑自动去重。

### 📖 展示架的「开盒」小彩蛋

在展示架布局里点一张唱片：镜头会先推近，唱片盒放大到画面中央，
然后像真的双开盒唱片一样**翻开**——左边是专辑信息和曲目，
右边是盘托上的唱片，点盘面即播放。`Esc` 或 × 合上放回原位。

### 🔍 字太小？放大

设置页有「界面缩放」滑块（50%–200%）；更顺手的是直接在墙里
按住 `Ctrl` 或 `Alt` 滚轮，立马变大变小。

### 🔒 锁定一张唱片

唱片 ⋯ 菜单里的「锁定」会让它的信息不能被编辑（依然可以播放、
换样式、删除），适合已经校对好信息的宝贝专辑。

### 📤 给朋友分享你的墙

顶栏 ⋯ 菜单里「**导出当前墙**」得到一个 `.mw` 文件，发给朋友，
对方点「导入 .mw 文件」就能原样摆出来。**你的 Cookie 和账号信息
不在墙文件里**，放心分享。

（会折腾的进阶用户还有「从 Git 仓库导入」，只支持电脑版。）

### 🎧 播放器页：一面专门用来听的墙

新建一个 `.mwp` 文件（和建墙一样，右键文件夹选「新建播放器」），
从任一面墙拖一张唱片进去，它就变成一台**唱片机**：
黑胶唱机、CD 机、大封面三种设备外观，白色/深色/随封面变色/木地板
四种背景。播放键会取封面的颜色，每天都有新鲜感。

### ▶ 和正在听的歌联动（Windows 电脑版）

在网易云音乐的设置里勾选「开启 SMTC」后，这个插件就能知道
你电脑上正在播什么：播放器页显示当前曲目、可以切歌；
墙上对应的唱片会亮起光环、跟着节奏转动。不用的话可以在
设置页关掉（不是 Windows 就自动忽略）。

### 🌐 界面语言

插件界面默认跟随 Obsidian 的语言（中文、繁體、English 都有），
也可以在设置页单独指定。

## 设置页都有什么

| 设置 | 一句话说明 |
| --- | --- |
| 界面语言 | 默认跟随 Obsidian，可单独指定 |
| 网易云账号 | 扫码登录、检查登录、登出；试听和播放需要登录 |
| 播放方式 | 默认插件内播放；也可切回网易云客户端播放 |
| 登录、接口与隐私说明 | 接口来源、凭据保存方式、播放权限与登出范围 |
| 播放歌单 | 仅客户端播放模式使用，默认尝试创建或复用专用私密歌单 |
| 默认唱片样式 / 展示架文字 / 列宽 / 播放器背景 / 界面缩放 | 外观偏好，随时改 |
| SMTC 正在播放 | 开/关「正在听的歌」联动（仅 Windows） |
| Git 仓库地址 / 分支 / 子目录 | 进阶：从 Git 仓库批量导入墙文件 |

## 常见问题

**点播放没反应，或者没放整首？**
请先在插件中扫码登录并检查网络。插件内播放会标明试听片段，并跳过没有可用音源的曲目；
完整播放仍取决于账号权限和歌曲版权。若选择客户端播放模式，还需安装并单独登录网易云客户端。

**扫码登录使用什么接口，凭据存在哪里？**
扫码流程参考 [NeteaseCloudMusicApiEnhanced](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced)，
复用现有加密层直接请求网易云，无需部署额外 API 服务器。
搜索、专辑与歌单接口保持原有实现。登录凭据（Cookie）未加密保存在当前库的插件设置中，
可能随库同步或备份，不会包含在 `.mw` 文件中。不要公开分享插件设置文件。
登出只清除本插件的凭据和播放歌单选择，不会登出网易云客户端或删除歌单。
详细说明和接口来源链接可在设置中查看。

**手机上能用吗？**
能浏览和搜索，也可使用插件内播放；客户端播放模式可以唤起网易云 App。
Git 导入和客户端「正在播放联动」只有电脑版有。

**我的收藏数据存在哪？会被上传吗？**
全部在你自己库里的 `.mw` 文件（普通文本文件），插件不会把任何
数据发到第三方——它只和网易云的服务器说话，目的仅仅是取专辑
信息、登录及获取播放音频。

**删错了怎么办？**
删唱片、删分组都有确认步骤（删非空分组还得亲手输入名字）。
真删了整个 `.mw` 文件的话，就和其他笔记文件一样，
去系统回收站找找。

**换电脑怎么搬？**
把 `.mw` 文件拷到新电脑的库里即可，安装插件后打开就是原样。

**歌词、下载、听歌排行有吗？**
没有，这个插件只做「收藏、整理、播放」这三件事。
