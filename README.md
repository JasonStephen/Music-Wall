# Music Wall（音乐墙）

把你的网易云音乐专辑，像真正的唱片一样摆上 Obsidian 里的一面墙。

每张专辑可以长成黑胶、CD、磁带或纯封面四种样子，整整齐齐码在墙上；
点一下唱片，就能直接在 Music Wall 内播放它。你收藏过什么、想听什么，
一眼就能看到。

所有收藏都存在你自己库里的一个 `.mw` 文件里——它就是一个普通文本文件，
可以发给朋友、可以备份，一切都在你自己手上。

## 三分钟上手

### 第一步：把插件装进 Obsidian

可通过 **BRAT → Add Beta plugin** 添加 `JasonStephen/Music-Wall`。手动安装请从 [最新 Release](https://github.com/JasonStephen/Music-Wall/releases/latest) 下载下面三个文件：

1. 找到你的 Obsidian 库所在的文件夹；
2. 在里面找到 `.obsidian` 文件夹 → `plugins` 文件夹（找不到 `.obsidian`？
   它是隐藏文件夹，Windows 在文件管理器「查看」里勾选「隐藏的项目」就能看到）；
3. 在 `plugins` 里新建一个叫 `music-wall` 的文件夹，把 **main.js、styles.css、
   manifest.json** 三个文件放进去；
4. 回到 Obsidian：设置 → 第三方插件，刷新后打开 **Music Wall** 的开关。

> 提示：本插件的发布页会提供这三个文件的打包下载，解压照做即可。

### 第二步：建一面墙

三选一，看哪个顺手：

- 在左边文件列表里**右键任意文件夹** → 选「新建音乐墙」；
- 点 Obsidian 最左侧边栏的**唱片图标**；
- 按 `Ctrl+P` 打开命令面板，输入「音乐墙」选对应命令。

墙上立刻出现一个新标签页——这就是你的第一面（暂时还空着的）音乐墙。

### 第三步：摆上第一张专辑

1. 点墙右上角的 **＋** 按钮，右上角会弹出一个小面板；
2. 输入专辑名（比如「范特西」）回车，从结果里挑出你要的那张；
   - 小技巧：直接把网易云 App 里「分享 → 复制链接」得到的链接贴进来也行；
   - 想一次加很多张：点面板里的「**批量**」按钮，把每张专辑的编号用分号隔开贴进去
     （编号就是网易云网页版专辑地址里 `id=` 后面的那串数字）；
3. 弹出的确认窗口里核对封面和曲目，点确认——唱片上墙了。

### 第四步：听

点一下墙上的唱片 → 在弹出的详情窗口里点播放。
默认在插件内按专辑曲目顺序播放，不需要安装网易云客户端，也不创建或替换账号歌单。
播放器页支持暂停、上一首/下一首、点击曲目、进度跳转和音量控制。
点击播放会留在当前墙；所有已打开音乐墙的底部播放条同步控制同一个播放器。
底部播放条顶部可拖动进度，歌曲信息旁提供上一首、播放/暂停和下一首；右侧依次为播放列表、音质、音量和展开按钮。
点击播放条封面、曲名或展开按钮，或左侧功能栏的播放器图标，即可打开完整播放器。
已有播放器标签页时会直接聚焦；播放器是独立页面，无需创建文件。
音量按钮位于曲目列表按钮右侧，点击展开竖向滑块。点击空白处可收起播放列表和样式面板。
播放器中的音质按钮仅列出当前歌曲与账号确认可用的档位，显示实际播放音质。
设置中可选择 128kbps、192kbps、320kbps、无损或 Hi-Res；不可用时自动选择较低的可用音质。
播放器内手动选择用于本次播放会话，尽量保留进度与暂停状态，不修改设置中的默认值。
桌面端支持边播放边缓冲，并提前准备下一首；流式通道不可用时自动使用完整下载播放。
设置中可分别调整暂停／继续与切歌交叉渐变，范围 0～6 秒，0 为关闭。
歌曲缓存默认上限为 1024 MB，可调整、查看已用空间或清理；设为 0 时关闭磁盘缓存，下一首仍可临时预加载。
缓存按账号与实际音质区分，保存在本机独立目录，不随音乐墙文件同步；清理缓存不打断正在播放的歌曲。
封面背景会等新图片准备完成后再平滑切换，图片暂时不可用时保留上一张背景。
在命令面板中也可暂停/继续或停止插件内播放。

唱片菜单中的「加入专辑队列」可追加待播专辑，不会打断当前播放。
在曲目面板展开「专辑队列」，可拖动或用箭头调整其他专辑顺序；移除当前专辑会播放下一张，队列为空时停止。
专辑模式支持顺序播放、队列循环和单曲循环；歌单模式额外支持随机播放。

左侧功能栏的「网易云音乐库」默认进入首页，显示欢迎信息和搜索框。侧边栏可进入搜索、我喜欢的音乐、我创建的歌单、我收藏的歌单；宽屏可收起为图标栏，窄屏使用抽屉。标签页和标题随当前板块、歌单或艺术家变化。
支持搜索单曲、艺术家、专辑和歌单；艺术家详情包含热门单曲及专辑。搜索单曲的「播放」会插在当前歌曲之后并立即切换，「下一首播放」只插队，不打断当前歌曲；原有歌曲保留，手动插队优先于随机与单曲循环。空队列会直接开始播放。
专辑搜索结果可试听、选择添加到某个音乐墙、加入专辑队列；音乐墙原有专辑搜索面板也提供入队按钮。歌单播放会替换歌曲列表，也可将歌单追加到列表。浏览内容不会打断播放。
「添加到音乐墙」按实际文件夹显示可展开的目录树，支持搜索墙名和路径；点击文件夹仅展开或收起，选择具体 `.mw` 文件后才添加专辑。
「我收藏的歌单」仅查看网易云已有收藏，此版本不提供新增收藏或取消收藏操作。
音乐库底部也提供与音乐墙相同的迷你播放栏，共享当前歌曲、队列与播放控制。
专辑队列与歌曲列表可在播放器的曲目面板切换，切换时保留原队列和播放位置。

在播放器的样式面板中，黑胶与 CD 外壳可选择白色、黑色、原木或跟随封面主色，默认呈现材质细节；外壳配色与页面背景分别设置。跟随封面时，黑胶盘片与转盘凹槽也使用封面主色。

**首次试听或播放会弹出登录二维码**，用网易云手机 App 扫描并确认即可，
也可以到插件设置中扫码登录或登出。音乐墙中的专辑浏览、搜索和整理无需登录；音乐库搜索可先浏览，个人歌单与喜欢的音乐使用当前登录账号。
播放队列只保留在内存中；关闭播放器标签页仍可继续听，停止播放、登出或关闭插件会清空队列。
设置中可以切回原来的「网易云客户端播放」；该模式整专连播仍使用专用歌单。

## 玩出花样

### 🎨 唱片的样子和墙的摆法

- **四种样子**：黑胶、CD、磁带、纯封面，随时换，整面墙一起变；
- **三种摆法**：网格（大海报式）、列表（紧凑一行行）、**展示架**
  （一面深色木架，唱片斜倚着，鼠标放上去会抽出来，黑胶还会滑出半张慢慢转）。

都在墙顶栏第一个图标「样式与布局」里，每个样式都有真实缩略图预览，
看哪个顺眼点哪个。你的选择会被记住，下次打开还是老样子。

### 🗂 分组：把墙分成几个区

在墙的空白处**点右键** →「新建分组」，就能把唱片分门别类
（比如「华语」「跑步听的」）。分组可以折叠、改名、排序；
想删掉一个分组时，如果里面还有唱片，需要你亲手输入分组名确认，
防止手滑。

### 🔃 找唱片：排序、筛选、搜索

- **排序**：手动排（从菜单进入布局编辑后拖动）、添加时间、专辑名、
  艺术家、发行时间、**评分**——想怎么排就怎么排，正排倒排随意组合；
- **筛选**：按艺术家、年代、评分挑，可以多选（比如只看「周杰伦」
  或只看评了 5 星的）；
- **搜索**：右上角放大镜，直接按关键词翻你的收藏。

### ⭐ 给专辑打分

右键任意唱片 →「**评分…**」，给 1 到 5 颗星。打完分的唱片
右上角会多一颗小星星，写着分数；详情里也会亮出对应星数。
之后可以按评分排序（把最爱的放最前）、按评分筛选（只看高分）。

评分存在墙文件里——把墙分享给朋友时，你的评分也会一起过去。

### ☑ 多选和批量搬家

顶栏「**多选**」进入挑选模式：点一张选中一张，然后可以一次性
把它们**批量迁移到另一面墙**。直接把选中的一叠拖到另一面
已打开的墙上也成。

### 🧱 很多面墙与搬家

墙不止一面：想建几面建几面（「华语精选」「2026 听后感」……）。
右键唱片 →「迁移到其他墙…」就能把唱片搬过去，按专辑自动去重。

### 📖 展示架的「开盒」小彩蛋

在展示架布局里点一张唱片：镜头会先推近，唱片盒放大到画面中央，
然后像真的双开盒唱片一样**翻开**——左边是专辑信息和曲目，
右边是盘托上的唱片，点盘面即播放。`Esc` 或 × 合上放回原位。

### 🔍 字太小？放大

设置页有「界面缩放」滑块（50%–200%）；更顺手的是直接在墙里
按住 `Ctrl` 或 `Alt` 滚轮，立马变大变小。

### 🔒 锁定一张唱片

唱片 ⋯ 菜单里的「锁定」会让它的信息不能被编辑（依然可以播放、
换样式、删除），适合已经校对好信息的宝贝专辑。

### 📤 给朋友分享你的墙

顶栏 ⋯ 菜单里「**导出当前墙**」得到一个 `.mw` 文件，发给朋友，
对方点「导入 .mw 文件」就能原样摆出来。**你的 Cookie 和账号信息
不在墙文件里**，放心分享。

也可从 Git 仓库同步音乐墙；移动端支持从公开 GitHub 仓库拉取。

### 🎧 播放器页：一面专门用来听的墙

点击左侧功能栏的播放器图标即可打开独立播放器页面。
从任一面墙拖一张唱片进去，它就变成一台**唱片机**：
黑胶唱机、CD 机、大封面三种设备外观，白色/深色/随封面变色/木地板
四种背景。播放键会取封面的颜色，每天都有新鲜感。

### ▶ 和正在听的歌联动（Windows 电脑版）

在网易云音乐的设置里勾选「开启 SMTC」后，这个插件就能知道
你电脑上正在播什么：播放器页显示当前曲目、可以切歌；
墙上对应的唱片会亮起光环、跟着节奏转动。不用的话可以在
设置页关掉（不是 Windows 就自动忽略）。

### 🌐 界面语言

插件界面默认跟随 Obsidian 的语言（中文、繁體、English 都有），
也可以在设置页单独指定。

## 设置页都有什么

| 设置 | 一句话说明 |
| --- | --- |
| 界面语言 | 默认跟随 Obsidian，可单独指定 |
| 网易云账号 | 扫码登录、检查登录、登出；试听和播放需要登录 |
| 播放方式 | 默认插件内播放；也可切回网易云客户端播放 |
| 默认播放音质 | 标准至 Hi-Res；每首歌按音源及账号权限自动匹配可用音质 |
| 登录、接口与隐私说明 | 接口来源、凭据保存方式、播放权限与登出范围 |
| 播放歌单 | 仅客户端播放模式使用，默认尝试创建或复用专用私密歌单 |
| 默认唱片样式 / 展示架文字 / 列宽 / 播放器背景 / 界面缩放 | 外观偏好，随时改 |
| SMTC 正在播放 | 开/关「正在听的歌」联动（仅 Windows） |
| Git 仓库地址 / 分支 / 本地目录 / 仓库目录 | 选择墙文件，预览差异后推送或拉取 |

### 用 Git 同步音乐墙（桌面端）

先在 GitHub 等平台创建存放音乐墙的仓库，并安装系统 Git。插件不会替你创建远程仓库。

GitHub 登录可从设置页「GitHub 账号 → 登录 / 选择账号」或同步窗口的账号按钮进入：点击「在浏览器登录 GitHub」，在浏览器完成授权，回到插件选择账号并点击「使用此账号」。此功能需要 Git Credential Manager（Git for Windows 通常附带；缺少时窗口提供安装链接）。密码和 OAuth 凭据由浏览器与系统凭据管理器处理，插件只保存账号名，不写入令牌。

指定账号用于 `https://github.com/...` 仓库的预览、推送和拉取；需要该账号具有目标仓库权限，组织仓库还可能要求组织授权。取消账号指定会恢复系统 Git 默认凭据，不会移除系统登录；SSH 和其他 Git 平台仍使用原有配置。登录不等于同步，必须预览并确认后才会推送文件。

在设置、音乐墙的更多菜单或命令面板打开「推送音乐墙到 Git」或「从 Git 拉取音乐墙」。填写仓库地址，分支留空使用远端默认分支（空仓库默认为 `main`）。

本地同步目录与仓库同步目录按相对路径对应，两者留空分别表示库根目录和仓库根目录。例如，库根目录中的 `MusicWall/Gaming/Game.mw` 会保持同一路径；若本地目录设为 `MusicWall`、仓库目录设为 `walls`，则映射为 `walls/Gaming/Game.mw`。

预览会列出新增、更新、相同和目标端独有的文件。可复选整个文件夹或单个 `.mw` 文件；推送默认选择包含 `.mw` 的文件夹，库根目录的单独 `.mw` 文件需手动选择；指定本地目录时，该目录中的 `.mw` 默认全选。拉取默认全选远端墙文件。点击文件名可查看专辑增减、设置变化及两端原文的差异，确认后才写入或推送。

只同步所选 `.mw` 文件和目录，不包含 Obsidian 配置、插件、登录信息、其他附件或音频缓存；另一端独有的文件会保留。更新会完整替换对应墙文件，不逐专辑合并，因此差异中的专辑移除也会生效。预览后本地或远端发生变化时需重新预览。拉取覆盖前会把原文件备份到当前库配置目录的 `plugins/music-wall/wall-sync/backups/`，不上传到远端。

同步由你手动发起，不会后台自动提交或定时同步。

### 在平板和手机上从 GitHub 拉取

在设置、音乐墙的更多菜单或命令面板打开「从 Git 拉取音乐墙」。移动端通过 GitHub API 读取公开仓库，不需要安装 Git 或登录；暂不支持私有仓库、推送、SSH 地址或其他 Git 平台。

填写 `https://github.com/用户名/仓库名`，分支留空使用默认分支；仓库同步目录和本地同步目录沿用上面的相对路径映射。拉取默认全选远端 `.mw` 文件，可取消勾选文件或文件夹、查看差异，确认后才写入。平板独有文件会保留，覆盖前会在同样的 `wall-sync/backups/` 目录备份原文件。关闭窗口会取消尚未完成的操作；已写入的文件会保留，重新预览可继续。

每次预览固定到一个远端提交，确认前再次检查分支及本地文件是否变化。文件按 Git blob 哈希校验，已读取的相同文件在本次插件运行期间会复用缓存。GitHub 匿名 API 存在访问限额；达到限额时请稍后重试。建议只选择需要的仓库目录；目前最多读取 500 个墙文件、单文件 5 MB、总计 20 MB。

## 常见问题

**点播放没反应，或者没放整首？**
请先在插件中扫码登录并检查网络。插件内播放会标明试听片段，并跳过没有可用音源的曲目；
完整播放仍取决于账号权限和歌曲版权。若选择客户端播放模式，还需安装并单独登录网易云客户端。

**扫码登录使用什么接口，凭据存在哪里？**
扫码流程参考 [NeteaseCloudMusicApiEnhanced](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced)，
复用现有加密层直接请求网易云，无需部署额外 API 服务器。
搜索、专辑与歌单接口保持原有实现。登录凭据（Cookie）未加密保存在当前库的插件设置中，
可能随库同步或备份，不会包含在 `.mw` 文件中。不要公开分享插件设置文件。
登出只清除本插件的凭据和播放歌单选择，不会登出网易云客户端或删除歌单。
设置中提供简短的账号与隐私提示。

**手机上能用吗？**
能浏览和搜索，也可使用插件内播放；客户端播放模式可以唤起网易云 App。
移动端还可从公开 GitHub 仓库拉取音乐墙；Git 推送、私有仓库同步和客户端「正在播放联动」仅在桌面端可用。

**我的收藏数据存在哪？会被上传吗？**
收藏保存在你自己库里的 `.mw` 文件（普通文本文件）。平时联网用于查询网易云专辑、登录及获取播放音频；只有在你确认 Git 推送时，所选 `.mw` 文件才会上传到指定的 Git 仓库。插件设置与登录凭据不在 Git 音乐墙同步范围内。

**删错了怎么办？**
删唱片、删分组都有确认步骤（删非空分组还得亲手输入名字）。
真删了整个 `.mw` 文件的话，就和其他笔记文件一样，
去系统回收站找找。

**换电脑怎么搬？**
把 `.mw` 文件拷到新电脑的库里即可，安装插件后打开就是原样。

**歌词、下载、听歌排行有吗？**
没有，这个插件只做「收藏、整理、播放」这三件事。
