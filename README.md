# Music Wall（音乐墙）

在 Obsidian 中整理专辑和歌单，创建自己的本地歌单，并在音乐库内播放。

[English](README.en.md)

## 安装

通过 BRAT 添加 `JasonStephen/Music-Wall`，或将发布包里的 `main.js`、`styles.css`、`manifest.json` 放入库的 `.obsidian/plugins/music-wall/`，然后在第三方插件设置中启用 Music Wall。

## 音乐墙

从音乐库打开音乐墙，依次进入「创建的歌单」「收藏的歌单」「收藏的专辑」。它们独立于网易云账号；账号歌单仍显示在「账号创建歌单」和「账号收藏歌单」中。

三个分类均支持多层文件夹。通过添加按钮收藏专辑、歌单或创建本地歌单，也可以将检索结果中的专辑、歌单拖入侧边栏对应分类或文件夹。同一位置的重复项目不能再次添加。

收藏的专辑和歌单在打开详情时联网加载最新曲目。本地歌单可以修改名称、简介和曲目，封面根据歌曲自动生成；通过歌单菜单克隆，可以按原顺序复制歌曲到同名本地歌单。

## 整理和播放

- 按住 Ctrl（macOS 为 Command）点击以多选，Shift 点击选择连续范围。
- 直接拖拽调整顺序；拖入文件夹可以移动专辑或歌单。正文和侧边栏使用相同顺序。
- 将检索结果或歌单里的歌曲拖入本地歌单，会复制歌曲并跳过重复项。
- 专辑网格提供封面、黑胶、彩胶、CD、磁带五种样式；彩胶根据封面取色。歌单网格和所有列表均使用封面，显示样式全局统一。
- 顶部提供排序、添加、搜索和布局切换。返回按钮与鼠标侧键返回上一页。
- 播放器在音乐库内从底部展开；点击左上角向下箭头收起，继续浏览。

## 数据

音乐墙统一保存在库内的 `MusicWall/music-wall.json` 中，可以随库备份。旧 `.mw` 文件不再作为独立音乐墙打开；已有迁移记录会保留，原文件由你自行整理。

网易云连接、播放、歌词和外观选项可在插件设置中调整。
